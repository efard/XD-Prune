# Result Evidence

This directory contains compact, reviewable evidence only.

- `depgraph/`: validated structural catalogues and operation manifests.
- `pruning/`: isolated T1/T2 tables, frozen rankings, masks, queues, and
  comparator manifests.
- `tables/`: aggregate exact-number tables used for reporting.

Training folders, checkpoints, prediction dumps, logs, caches, NCNN binaries,
and raw board archives are excluded. Aggregate CSV values were transcribed from
completed local experiment/evaluation records; blank fields indicate metrics
that were not available in the retained source record, not zeros.
