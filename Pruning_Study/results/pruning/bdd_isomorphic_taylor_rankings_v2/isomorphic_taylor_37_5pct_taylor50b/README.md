# BDD Isomorphic-Taylor competitor

Controlled adaptation of Isomorphic Pruning (Fang et al., ECCV 2024) using first-order Taylor importance. The original paper/source targets ImageNet CNNs and transformers, so YOLO26n custom C3k2/C2PSA units use this project's validated coupled structural rules. This is a one-shot ranking/mask stage; no validation/test data, pruning, or recovery occurs here.
