# Selected Validation Visuals

This directory contains three archived validation prediction grids from the
software workflow:

- `fp32_baseline_validation_predictions.jpg`: FP32 baseline predictions.
- `int8_validation_predictions.jpg`: INT8-engine predictions.
- `structured_pruning_validation_predictions.jpg`: structured-pruned-model
  predictions.

They are included as qualitative visual evidence only. They are not a matched
accuracy, latency, or hardware-acceleration comparison; consult the result
records in the numbered workflow directories for the associated quantitative
evidence.
